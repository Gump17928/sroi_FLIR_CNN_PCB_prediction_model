# Thermal Post-Processing

## Overview
This folder contains tools for post-processing ResearchIR thermal data exports with advanced filtering and spatial thermal coupling analysis.

## Folder Structure
```
thermal_post_processing/
  inputs/                           # Input data
    ResearchIR_Outputs_*/           # ResearchIR CSV exports
    hbridge_pcb_components_enhanced.csv  # Component coordinates
  outputs/                          # Analysis results
    thermal_analysis_results/       # Output folder with plots and CSVs
  researchir_post_processor.py      # Main analysis script
  component_grouping_config.json    # Optional custom grouping rules
```

## Quick Start

### Interactive Mode (Recommended)
The script includes an interactive configuration UI to verify settings before processing:

```powershell
cd thermal_post_processing
python researchir_post_processor.py
```

The UI allows you to:
1. View current configuration
2. Change input folder
3. Change output directory
4. Modify coordinates file
5. Adjust proximity threshold
6. Enable/disable spatial coupling analysis
7. Toggle debug mode
8. Validate file paths
9. Continue with processing

### Command-Line Mode
Skip the UI for automated workflows:

```powershell
# Use defaults
python researchir_post_processor.py --no_ui

# Custom parameters
python researchir_post_processor.py --no_ui \
    --input inputs/ResearchIR_Outputs_HBridge_15s \
    --output outputs/my_analysis \
    --coordinates inputs/hbridge_pcb_components_enhanced.csv \
    --proximity_threshold 15.0
```

## Analysis Features

### Phase 1: Data Loading
- Automatically detects CSV/TXT format
- Handles multi-file exports from ResearchIR
- Validates data integrity

### Phase 2: Filtering Analysis
Compares multiple filtering methods:
- **No Filter:** Raw data baseline
- **Moving Average:** Smooths temporal noise
- **Median Filter:** Removes outliers (recommended)
- **Savitzky-Golay:** Preserves peak shapes

**Outputs:**
- `filtering_method_comparison_grid.png` - Visual comparison
- `filtering_comparison_median.png` - Median filter details

### Phase 3: Component Analysis
- Groups components by type (ICs, regulators, drivers, etc.)
- Calculates statistics (mean, max, min, std dev)
- Identifies thermal hotspots
- Generates per-component plots

**Outputs:**
- `thermal_analysis_summary.png` - Overview plot
- `thermal_analysis_summary.csv` - Statistical table

### Phase 4: Spatial Thermal Coupling
Analyzes thermal interactions between nearby components:
- Distance-based coupling detection
- Heat source identification
- Coupling strength quantification
- Visualization of thermal relationships

**Outputs:**
- `thermal_coupling_heat_sources.pdf` - Heat source map
- `spatial_thermal_coupling_map.pdf` - Coupling visualization

### Phase 5: Potted Condition Analysis
Risk assessment for potting/encapsulation:
- Evaluates sustained temperature exposure
- Identifies components at risk
- Provides risk scoring
- Requires coupling metrics from Phase 4

**Outputs:**
- `potted_condition_risk_analysis.csv`

## Command-Line Options

```
--input <folder>           Input folder with ResearchIR exports
                          Default: inputs/ResearchIR_Outputs_HBridge_15s

--output <folder>         Output directory for results
                          Default: outputs/thermal_analysis_results

--coordinates <csv>       CSV with component X,Y coordinates (mm)
                          Default: inputs/hbridge_pcb_components_enhanced.csv

--proximity_threshold <mm> Distance threshold for coupling analysis
                          Default: 10.0 mm

--no_spatial              Disable spatial coupling analysis

--custom_groups <json>    JSON file with custom component grouping

--debug                   Enable debug output

--no_ui                   Skip interactive configuration UI
```

## Configuration File

`component_grouping_config.json` allows custom component grouping rules:

```json
{
    "groups": {
        "Power_Management": ["VR*", "PS*"],
        "Custom_Group": ["U1", "U2", "U3"]
    }
}
```

## Input Requirements

### ResearchIR CSV Exports
- One CSV file per ROI (component)
- Format: Time(s), Temperature(°C)
- Files named by component designator

### Coordinates CSV
- Format: Component, X(mm), Y(mm), ROI_Type
- Generated by SROI pipeline
- Required for spatial coupling analysis

## Output Files

### Generated Plots (PNG/PDF)
- Filtering comparison grids
- Component thermal profiles
- Statistical summaries
- Spatial coupling maps

### CSV Reports
- Statistical tables
- Risk assessments
- Filtering comparison data

| 2 | Filtering | Thermal time series | Filter comparison plots |
| 3 | Component Analysis | Thermal data | Statistical plots/tables |

## Typical Workflow

1. **Export from ResearchIR:**
   - Use SROI file to define ROIs
   - Export thermal data as CSV
   - Place in `inputs/ResearchIR_Outputs_*/`

2. **Run Analysis:**
   ```powershell
   python researchir_post_processor.py
   ```

3. **Review Results:**
   - Check `outputs/thermal_analysis_results/`
   - Review plots and CSV tables
   - Use for thermal design validation

4. **Iterate if Needed:**
   - Adjust proximity threshold for coupling
   - Modify component groupings
   - Re-run with different filters

## Troubleshooting

**Issue:** File not found errors  
**Solution:** Use interactive UI to validate paths (option 8)

**Issue:** No spatial coupling results  
**Solution:** Ensure coordinates CSV is provided and has correct format

**Issue:** Plots look cluttered  
**Solution:** Adjust component grouping or use custom groups

**Issue:** Import errors  
**Solution:** Install required dependencies with pip
